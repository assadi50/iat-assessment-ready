# Assessment Ready: Readiness Command Center (demo)

An illustrative demo by Knowledge Group for the Institute of Applied Technology.
It shows how a readiness dashboard tracks the Abu Dhabi Government Performance and Excellence Model (2026) criteria from baseline to mock assessment.

All figures, owners and evidence items are illustrative examples. They are not IAT data.

Live page: https://assadi50.github.io/iat-assessment-ready/
